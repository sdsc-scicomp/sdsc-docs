SDSC docs &mdash; Lighthouse accessibility snapshots

Snapshot of automated (Lighthouse) accessibility results for the two proof-of-concept SDSC documentation sites, captured on 2026-09-09. Reports are generated by each repo's lighthouse.yml GitHub Actions workflow (Lighthouse CI).

MkDocs site (sdsc-scicomp/expanse-docs) — accessibility 79 to 84

Fails WCAG 2.1 AA. Common failures: prohibited ARIA attributes, missing required ARIA attributes, buttons/links without accessible names, out-of-order headings, unassociated table headers.
